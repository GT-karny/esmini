# 実機G29でのVD→MD→VD往復移管（フィールドテスト専用）

**このシナリオは実機のG29ステアリング/ペダルを接続したフィールドテスト専用であり、自動ゲートでは走らない。**
GUIから何気なく実行しても、意図した検証（実機での力の授受と往復移管）にはならない点に注意すること。
ヘッドレス版`scenario_headless_handover_vd_md_vd.xosc`と同一のストーリーボード構成で、ManualDriveの入力元だけ物理G29に差し替えてある。

## 検証の狙い

xosc内コメントは、この構成が修正3点すべてを通ると述べる。
(1) 移管直後にMDが人の入力なしで運転を始めるか。
(2) AUTO_RESUMEでVDがドメインを取り戻すか。
(3) HVD/テレメトリが実際に運転している側から出るか。
VD区間はサーボON（AIの指令舵角へホイールが追従）、MD区間はサーボOFF（人が操舵する側なのでサーボが出ると綱引きになる）と、区間によって「正常」の見え方が変わる点をxosc内コメントは強調している。

## シーン構成

| 項目 | 内容 |
| :-- | :-- |
| 道路 | `e6mini.xodr` |
| 自車 | road 0 / lane -3 / s=20→s=1400、目標速度8.333 m/s（Story Eventでlinear 3.0s掛けて到達） |
| ドメイン所有 | t<15.0s: 横=VD・縦=VD（サーボON）／t>15.0s以降: 横=MD・縦=MD（サーボOFF）／AUTO_RESUME後: 横=VD・縦=VD（サーボON） |
| 他エンティティ | なし |
| 走行時間 | シミュレーション時間 180 s 超過 |

## 進行

1. Init：Ego位置teleport、速度8.333 m/sへstep。VirtualDriverController（ConfigFile `virtual_driver_realwheel.json`、サーボON）を横・縦ともActivate。ManualDriveController（ConfigFile `manual_drive.json`）は宣言のみ。
2. t=0..15s：VDが運転し、ホイールがAIの舵に追従して動く。押し返すとMANUALにラッチして力が抜け自分で操舵できる（これはVD内部のoverrideであり、シナリオレベルの移管ではない）。
3. t>15.0s（パラメータ`HandoverAt`）：ReleaseVDイベントに続きTakeMDイベントが発火し、シナリオによる全ドメイン移管が起きる。何も触らずに速度計を見る。
4. 移管後、ペダル・ハンドルで普通に運転できる。
5. 奪い返す：ハンドルを中立付近へ戻してからAUTO_RESUME（G29既定=ボタン3）を押す。車が自力で走り出しホイールに力が戻れば(2)合格。押し返せば再びMANUALにラッチでき、この往復は何度でもできる。
6. t>180s：StopTriggerでシミュレーション終了。

## 期待する挙動

自動matcherは無く、xosc内コメントに記載された実機での観測手順が判定手段になる。

- t=15s以降、何も触らず速度が惰行で落ちていけば(1)合格（MDが積分しエンジンブレーキが効いている）。完全に一定のままなら(1)不合格。
- 中立に戻してからAUTO_RESUMEを押すと車が走り出しホイールに力が戻れば(2)合格。xosc内コメントによれば、復帰の1フレーム目だけは直接軸経路（|steering| > 0.05 axis-frac、ハンドル約22.5°相当、デバウンス無し）が生きており、大きく切ったまま押すとその場で即MANUALに再ラッチする（仕様どおりの挙動）。
- 【未確認】この構成は2つのSDL2WheelInputが同一G29デバイスを同時に開く。参照カウント方式で同じハンドルが返るはずだが、xosc内コメントによれば実機で確認した記録はまだ無い。起動時にログで`SDL2WheelInput: Opened`が2行出ること、`SDL_HapticNewEffect`の失敗ログが出ていないことを確認する必要がある。
- 異常時はウィンドウを閉じれば停止する。ウォッチドッグは|force| >= 0.570が2.0秒継続すると強制終了し力を落とす。
